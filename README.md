# 行境 · 中国护照签证地图

桌面优先的全屏世界地图查询页。我的证件、国家详情、筛选、列表和图例浮在地图上并可收起；初始页面默认折叠两侧面板。支持中文 / 英文搜索、签证方式与洲别筛选、地图缩放，以及按已有旅游签证 / 永久居留的签发地查看第三国便利途径。

“用已有签证解锁免签”入口分为旅游签证和永久居留两组，直接多选美国、加拿大、澳洲、申根、日本、英国。选择即时更新地图，再点一次取消，也可一键清空。入口与面板实时提示额外发现的有条件免签目的地数量，可一键查看这些国家；计数去重并排除本来就免签、仅使用已有本国 / 申根证件和仍须申请电子许可的途径。具体适用条件保留在国家详情。无需填写旅行日期、停留天数、到期日、入境次数、签证类别代码或使用记录。

勾选申根旅游签证后，全部 29 个申根国标为“已有申根签证”；申根永久居留同样覆盖申根区内短期旅行。已有目的地本国签证 / 永居也标为“已有证件”，使用独立蓝色，并提供对应筛选。已有签证与普通护照免签分别显示；申根区共享的 90 / 180 天额度、签证获批天数、有效期、入境次数及地域限制在详情中说明，不假定每国都有新的 90 天。

澳洲永居前往新西兰是独立的签证豁免途径，显示“有条件免签 · 需 NZeTA”。须持有效澳洲永久居留签证 / Resident Return Visa，保有返澳旅行资格并符合入境要求；抵达获批 Australian Resident Visa 后可无限期居留。澳洲旅游签证从澳赴新的途径仍须 NZeTA，并有 3 个月上限；同时选择旅游签证和永居时，页面优先显示永居途径。

## 运行

当前处于本地开发阶段。按用户要求，未完成前只修改本地页面；未经用户明确要求，不发布或部署线上版本。

项目是自带地图和绘图库的静态网站，无需运行 `npm install`。安装 Node.js 与 Python 3 后，在项目根目录启动：

```powershell
npm run start
```

打开 `http://127.0.0.1:4173/`，停止服务按 `Ctrl+C`。`npm run dev` 使用同一预览服务；也可直接运行 `python scripts/serve-local.py`。默认端口为 4173，同一时间只启动一个预览服务。JSON 数据通过本地 HTTP 加载，不能直接双击 HTML 运行。

本地预览关闭 HTTP 缓存，并按文件内容为 JS / CSS 添加版本参数；修改规则后重新打开或刷新页面会加载当前文件，避免旧缓存造成界面与数据不一致。

## 数据范围

- 中国普通护照、个人短期旅游；最新资料快照 2026-10-01，各条记录保留自己的核对日期。
- 已录入 196 个目的地：索引中的 193 个外国独立国家，以及巴勒斯坦、库克群岛、纽埃。中国及港澳台按专用证件逻辑单独显示；部分海外属地和特殊地区仍待逐项核实。
- 已录入第三国证件途径的 21 个目的地：墨西哥、巴拿马、秘鲁、黑山、哥斯达黎加、哥伦比亚、智利、格鲁吉亚、吉尔吉斯斯坦、菲律宾、爱尔兰、北马其顿、摩尔多瓦、塞浦路斯、加拿大、伯利兹、多米尼加、洪都拉斯、阿根廷、乌拉圭、新西兰。
- 第三国证件筛选包括免签和其他便利途径。新西兰从澳大利亚赴新途径仍需 NZeTA，显示为电子授权；提前申请免费 ETA、预批准落地签不当作无需手续的免签。
- 页面分别选择旅游签证和永久居留，签证默认按旅游用途查询，不把普通居留自动当作永居。紫色表示所选证件类型有第三国免签途径，不表示已核验证件的具体有效期、入境次数或使用记录。
- 巴拿马采用使馆公布的 2024 年修订，不沿用旧版的已使用和六个月条件。
- 多次入境、剩余有效期、已使用、签证类别、机场 / 路线等具体要求留在国家详情中；已选证件涉及的途径自动展开，其他途径可折叠查看。未确认的停留期限明确标注待核实。
- 申根作为区域选项，不伪造具体签发国。规则只接受部分申根国家时，详情会注明其签发地限制，例如乌拉圭的欧盟成员国范围。
- 页面按浏览器当前日期判断已公布的政策及单条规则生效 / 截止日期。柬埔寨限期免签到期后回退到普通落地签途径；巴西临时免签到期后显示现行日期政策待核实。
- 不自动更新政策，不计算过去旅行的累计停留，不代替护照、入境材料与入境机关审核。官方依据和核实日期可在详情中查看。
- 仅保存当前页面的国家 / 区域与证件类型选择，刷新后清空，不收集证件号码、照片或其他证件信息。

## 维护

`dist/policies.js` 保存原有规则；`dist/policy-expansion.js` 保存逐国扩展、近期公告、核对日期及官方链接；`dist/engine.js` 实现条件判断；`dist/main.js` 连接交互与地图。浏览器与 Node 验证均须先载入原有规则，再载入扩展。

`scripts/fetch-consular-guides.py` 可下载领事服务网的国别入境指南，原始文本缓存在被 Git 忽略的 `.policy-research/`。脚本不自动分类或覆盖政策；旧指南与近期公告冲突时需人工核对目的地官方 / 使领馆的新公告。

```powershell
node scripts/verify.js
```

`evaluateProfile` 用于页面的简化选择：按签发地 / 区域和旅游签证 / 永居发现途径，不生成虚构的到期日期、入境次数或使用记录。原有 `evaluate` 及精确规则保留用于资料维护和回归验证。

规则测试覆盖国家 / 区域选择、签证与永居区分、部分申根签发地限制、清空后的基础政策、现行规则有效期，以及原有精确判断回归。`node scripts/browser-qa.js` 检查真实地图点击、拖动、折叠面板、多选、清空、国家详情和不同窗口尺寸。

WebMCP 注册仅在浏览器支持原生 `document.modelContext` 时启用。浏览器不支持时不影响页面查询；原生验证状态记录在 `qa-results.json`。

地图使用 Natural Earth / world-atlas 的 1:10m 边界，保留小国多边形，不使用圆点替代。梵蒂冈和马尔代夫采用 Natural Earth 原始边界，避免量化压缩使轮廓退化或错误覆盖地图。搜索或选择国家会自动放大；轮廓仍有底图本身的概括和精度限制。

世界总览和区域视图使用由同一底图生成的简化边界，放大后切回完整边界。小国轮廓单独保留。绘制按浏览器帧合并，屏幕外国家暂不绘制，拖动期间暂停悬停提示。地图数据更新后运行 `node scripts/prepare-map-lod.js` 重新生成两个精度级别；`node scripts/map-performance.js` 可重复本地性能测试。

国家与地区索引来自 mledoze/countries，绘图依赖 D3 和 topojson-client。源库版权许可见各资产文件内头部及其官方仓库。
